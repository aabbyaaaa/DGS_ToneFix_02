工程師客服回覆工具 使用說明

版本基準：feature/product-list-fallback-test

1. 介面總覽

  • 上方是輸入列：客戶姓氏/稱謂、技術文字、OCR、開始轉換。
  • 中間是三種回覆卡：精簡、標準、正式。
  • 右下角是剪貼區 FAB，點擊可展開右側抽屜。
圖 1：首頁介面總覽

2. 產生三種回覆

  1. 在輸入框貼上技術內容（可搭配 OCR）。
  2. 按「開始轉換」。
  3. 系統會依序產生：精簡 → 標準 → 正式。
圖 2：產生三種回覆（精簡、標準、正式）

3. 加入剪貼區與重組內容

  1. 直接點任一段落或列點，即可加入剪貼區。
  2. 抽屜會自動展開，便於立即確認。
  3. 可拖曳排序、編輯文字、刪除單段。

目前「獨特內容標註」採 列點級 比對（更精準）， 並且「工程師的建議如下：」後會保留空一行。

圖 3：剪貼區抽屜（加入、排序、編輯）

4. Copy All 一鍵複製

  • 在剪貼區右下方按 Copy All。
  • 成功會顯示 Copied! 狀態。
圖 4：Copy All 成功狀態

5. 常見問題

Q：出現 Failed to fetch 怎麼辦？

  • 有可能是LLM過期或是API沒錢，請直接跟分機124 陳宛均Abby聯繫即可。
